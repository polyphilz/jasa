# jasa

Explore one research question as a tree instead of one long chat.

jasa is a local-first desktop app for studying something hard — a lecture, a paper, a codebase — with an AI research companion. Each **session** is a single root question (for example, *"How do modern large language models work?"*). Answers branch into follow-up questions on a smooth, pannable canvas, so every rabbit hole gets its own thread instead of bloating one linear context window.

When jasa answers a question, it sends the **linear chain of questions and answers from the root down to that node** as context — sibling branches stay isolated by construction.

Answers are generated by the [Claude Code](https://claude.com/claude-code) CLI you already have installed (`claude -p`), using your existing subscription. No API keys, and your data never leaves your machine except through the CLI itself. The agent is restricted to web search/fetch tools.

## Status

Early MVP. Expect rough edges.

## Install

Grab the `.dmg` from the [latest release](https://github.com/polyphilz/jasa/releases/latest), open it, and drag jasa to Applications. The build is universal — Apple Silicon and Intel.

Releases are not signed by Apple, so macOS refuses to open the app on first launch and claims it "is damaged". It isn't; that is just what Gatekeeper says about unsigned downloads. Clear the quarantine flag once:

```sh
xattr -cr /Applications/jasa.app
```

You still need [Claude Code](https://claude.com/claude-code) installed and logged in — jasa shells out to the `claude` CLI and uses your existing subscription.

## Requirements

- macOS (only platform exercised so far)
- [Claude Code](https://claude.com/claude-code) installed and logged in (`claude` on your PATH or in `~/.local/bin`)
- Rust toolchain, Node 22+, pnpm (to build from source)

## Develop

```sh
cd app
pnpm install
pnpm tauri dev
```

Dev builds keep their data in `app/.data/local` (see the `tauri` script); release builds use the platform app-data directory. Override with `JASA_DATA_DIR`.

Sessions are stored as plain JSON, one file per session, under `<data dir>/sessions/`.

## Checks

```sh
cd app
pnpm check   # oxlint + oxfmt --check + tsc + vite build
```

## Release

Bump the version in **both** `app/package.json` and `app/src-tauri/tauri.conf.json`, then push a matching tag:

```sh
git tag v0.1.0 && git push origin v0.1.0
```

`.github/workflows/release.yml` builds a universal macOS bundle and attaches the `.dmg` to a draft GitHub Release for you to review and publish.

To sign and notarize (removes the `xattr` step for users), add `APPLE_CERTIFICATE`, `APPLE_CERTIFICATE_PASSWORD`, `APPLE_SIGNING_IDENTITY`, `APPLE_ID`, `APPLE_PASSWORD` and `APPLE_TEAM_ID` as Actions secrets. The workflow picks them up automatically and drops the quarantine instructions from the release notes.

To build a bundle locally:

```sh
cd app
rustup target add x86_64-apple-darwin   # once, for the Intel half
pnpm tauri build --target universal-apple-darwin
```
